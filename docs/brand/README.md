# Hysilens 品牌素材

- `logo.png`：选定的紫发猫耳头像，原始透明 PNG，可用于文档或海报排版。
- `readme-banner.png`：1600 × 640 圆角 README 横幅，四角透明。

- `app-icon.png`：1024 × 1024 App Icon，淡紫色圆角矩形背景，四角透明。

以上图片均使用当前确认的角色版本，不保留 HTML 排版文件。横幅与 App Icon 的圆角已经包含在 PNG 内，四角透明。

`apps/desktop/src-tauri/icons/icon.png` 为 256 × 256 应用图标；同目录 `icon.ico` 包含 16、24、32、48、64、128、256px 七档尺寸，用于 Windows 可执行文件。
