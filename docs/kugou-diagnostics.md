# 酷狗诊断报告

在 Windows 的「设置 → 酷狗诊断」点击「导出诊断报告」，选择 JSON 保存位置，并保持酷狗播放，等待显示导出完成。取消保存不会采集报告。未找到酷狗、版本未适配或内存读取失败时，也会导出已取得的信息和错误。

建议正常电脑和异常电脑播放同一首歌后分别导出。报告包含本机模块路径，分享前可检查路径中是否有需要隐藏的个人目录名。

两条指针链都失败时的备用方案与验证顺序见[酷狗进度采集备用方案](./kugou-fallback-research.md)。

## 报告内容

- `schemaVersion`：报告格式版本，当前为 2；`hysilensVersion`：Hysilens 应用版本。
- `application`：正在运行的 Hysilens 可执行文件路径、SHA-256、大小、修改时间及调试/发布构建标识，用于区分版本号相同的构建。
- `system`：Windows 产品、版本、构建号与补丁修订号，系统架构、CPU 型号和逻辑处理器数、内存总量与可用量。
- `processes`：所有酷狗候选进程的 PID、进程名、进程/系统架构及诊断错误。
- `modules`：酷狗主程序、`kgplayer.dll` 和 `kugou.dll` 的路径、完整文件版本、SHA-256、加载基址和模块大小。版本相同时先比较 SHA-256。
- `samples`：每个受支持的播放进程采集 13 次，间隔 250 毫秒，覆盖至少约 3 秒；每次尝试该版本的所有已知布局。各进程按顺序采集，报告记录起止时间戳和实际采样耗时。`preferredUsableLayoutIndex` 是本次采样通过校验的最高优先级布局索引，全部失败时为 `null`，不表示当前播放器连接实际选用了该布局。
- `mediaBefore` / `mediaAfter`：整个报告及每次采样前后的酷狗 SMTC 会话，包括歌名、歌手、专辑、播放状态、原始和推算进度、总时长、更新时间、速率及错误。系统媒体会话初始化失败时记录 `mediaError`，继续采集内存数据。
- `runtimeBefore` / `runtimeAfter`：采集前后 Hysilens 当前会话、播放器采样、来源、歌词状态、缓存错误及快照序号，附带应用版本和协议版本。保留错误发生时应用实际展示的状态，不导出完整歌词正文。
- `layouts`：偏移、指针链、单位换算和每次读取结果。`position` 为进度，`progressUsable` 表示进度本身是否通过校验；`durationSteps` 为逐级指针读取，`duration` 为最终时长字段，`timeline` 为进度与时长共同校验后的毫秒时间轴。
- `identityEntry`：内存歌曲身份的 AOB 定位结果（调用点、getter、根槽的模块内 RVA），或定位失败原因。每次连接只扫描一次模块可执行节，不逐帧扫描。
- 每个 `samples[].identity`：当前队列条目 ID、来源类型、来源歌曲 ID、两份资源 hash、`MixSongID`、推荐歌词 ID，或读取失败原因。身份读取独立于时长链，失败不会丢弃有效进度。
- 公共会话仅发布通用、不透明的 `trackId`；酷狗身份明细与失败原因通过专用报告的 `process.identityEntry` / `samples[].identity` 导出，不进入播放协议。`matchedMemoryHash` 表示使用内存 hash 关联到了本地 KRC。

原始字节保存在 `bytesHex`；指针与地址使用十六进制字符串，避免 JSON 数字精度损失。即使时间轴校验失败，报告也保留进度、原始时长和换算后的秒数。例如原始时长 `528`、每秒 `1000` 单位对应 `0.528` 秒，不能当作有效歌曲时长。

酷狗 `20.1.61.28014`（`kgplayer.dll 1.2.0.523`）连接时优先使用时长链 `0x108 → 0x8C`，读取或校验失败后尝试 `0x130 → 0x130 → 0x2A4`。诊断报告按此顺序记录两条链的结果，便于比较。

实时采集已将进度和总时长拆开：只要进度读取与独立校验成功，就保留连接、发布进度并继续同步歌词；两条时长链均失败时，`durationMs` 为 `null`，不清空有效进度。每次采样都会重新按优先级尝试时长链，数值恢复后可重新提供总时长。诊断中的 `timeline.error` 仍保留时长问题，需结合 `progressUsable` 和 `runtimeAfter` 判断实际运行状态。

时间轴的各读取点均通过 `VirtualQueryEx` 查询内存区域状态、保护属性和大小；`region.nearby` 保存该地址前后各最多 64 字节的原始数据、起始地址和目标偏移，实际读取范围限制在该内存区域内，跳过未提交、不可访问或 guard 区域。读取失败时保留错误和可获得的 HRESULT。查询权限不足会单独记录，不阻止已有只读权限的时间轴采样。单个字段失败不会阻止其他系统信息导出。

报告按已知布局读取时间轴、邻近的少量字节及歌曲身份字段，并对受支持模块的可执行节进行有上限的 AOB 特征定位；不扫描整个堆寻找字符串，不导出完整进程内存，也不会上传到网络。内存片段可能包含附近字段，分享前可检查报告。导出在后台任务中执行，不改变当前播放器连接或播放设置。采样期间数据可能变化，报告记录前后状态供判断切歌或暂停等情况，不保证各字段是原子快照。
