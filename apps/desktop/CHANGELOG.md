# @hysilens/desktop

## 0.3.0

### Minor Changes

- 新增独立的 `/browser-info` 诊断页，可在直播软件浏览器源中查看 Chromium 版本、实时帧率及帧耗时，便于排查不同电脑的显示差异

### Patch Changes

- 改进直播软件浏览器源的兼容性：以 Chromium 100 为构建目标，补充配置复制、歌词定位、插件布局和配色的兼容处理
- 内置「滚动歌词」和「透视描边」不再跟随 Windows 的减少动态效果偏好，避免系统设置使歌词滚动和切句动画消失
- 整理播放设置逻辑，保持现有配置与操作行为

## 0.2.0

### Minor Changes

- 新增系统托盘支持，关闭窗口后继续采集歌词，并释放窗口 WebView 以减少内存占用

- 新增可选的酷狗 CDP 增强模式：通过本机调试端口连接酷狗内嵌网页，读取播放状态、进度、时长和歌曲 hash / 曲库 ID；读取失败时自动回退到原有采集方式，支持从界面启动酷狗及创建增强快捷方式

- 增强模式新增歌词网络请求：向酷狗歌词服务发送当前歌曲的 hash、曲库 ID 和时长，查询推荐歌词 ID 并下载 KRC；优先按推荐 ID 匹配本地缓存，匹配不到时使用下载的歌词，不发送账号或设备信息，下载结果仅保存在内存中

- 改进酷狗内存采集：支持按播放器版本选择内存布局，通过歌曲身份准确匹配缓存歌词

- 新增播放进度显示、平台诊断导出和已安装插件卸载，预览默认跟随实时播放

- 优化设置布局、弹窗和插件操作反馈，控制界面改用 IPC 与事件订阅同步状态

- 修复启动首屏白屏：提前应用已保存的界面主题，设置窗口初始背景，并在控制页加载期间显示提示

- 改进内置歌词插件的字体、透视效果、当前行居中和换行宽度，修复 overlay 权限及忽略歌词片段的显示问题
