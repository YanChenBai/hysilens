# @hysilens/plugin

[Hysilens](https://github.com/YanChenBai/hysilens) 歌词插件 SDK：插件运行时、`PluginHost`、配置声明、Vite 集成，以及 `hysilens` CLI（创建、开发调试与打包插件）。

```sh
npx @hysilens/plugin create my-plugin
```

插件接口、配置声明与沙箱限制见 [歌词插件开发](https://github.com/YanChenBai/hysilens/blob/main/docs/renderer-plugins.md)。
